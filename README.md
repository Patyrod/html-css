📂 Estrutura do Repositório
Todos os exercícios e projetos estão organizados na pasta exercicios/. A numeração dos exercícios (ex001 a ex027) segue a progressão didática do curso.

Módulo 1: Primeiros Passos em HTML5
ex001 - ex005: Primeiros documentos HTML, estrutura básica, hierarquia de títulos.
ex006 - ex009: Formatação de texto, listas e links.

Módulo 2: Mídias e Interatividade
ex010: Uso de links internos e externos.
ex011: Inserção de imagens e áudios.
ex012: Inserção de vídeos em diferentes formatos.

Módulo 3: Estilizando com CSS3
ex013 - ex015: Estilos CSS inline, interno e externo.
ex016: Cores em CSS (paletas, gradientes).
ex017 - ex018: Tipografia e fontes com Google Fonts.
ex019 - ex022: Seletores personalizados, pseudo-classes e pseudo-elementos, e fundos (backgrounds).

Módulo 4: Estruturas Avançadas
ex023: Criação de tabelas simples e complexas.
ex024: Uso de Iframes.
ex025: Criação de formulários com diferentes tipos de input.
ex026: Media Queries e primeiros passos em Design Responsivo.

Módulo 5: Layouts Modernos (Em Andamento)
ex027: Flexbox (Múltiplos exemplos de flex-direction, justify-content, align-items, etc.).
Próximos Passos: Grid Layout e Projeto Final de Portfólio.

🔗 Como Visualizar os Projetos
Para visualizar qualquer exercício, basta navegar até a pasta correspondente (exercicios/exXX) e abrir o arquivo index.html (ou o arquivo principal) diretamente no seu navegador.
